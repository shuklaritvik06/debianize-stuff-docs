Installing the Tools

Install these once on your Debian/Ubuntu machine before packaging anything.

sudo apt install build-essential devscripts debmake debhelper-compat \ dh-make lintian dpkg-dev fakeroot sudo apt install sbuild schroot sudo apt install git-buildpackage sudo apt install piuparts autopkgtest wrap-and-sort debputy sudo apt install quilt uscan uupdate

After installing, configure your identity so changelog entries are attributed correctly:

export DEBEMAIL="you@example.com" export DEBFULLNAME="Your Name"
