The 4-Step Packaging Workflow

Every Debian package follows this same pattern, from a tarball to a working .deb.

1

Get the upstream source

Download the original program's tarball (e.g., mypkg-1.0.tar.gz) and unpack it. This is your starting material — never modify it directly.

tar -xf mypkg-1.0.tar.gz cd mypkg-1.0
2

Generate template files with debmake

Run debmake inside the unpacked source. It reads the existing build files and generates a debian/ folder full of templates — placeholders you must edit.

debmake
3

Edit the template files

Open each file in debian/ and fill in the real information: package description, dependencies, copyright, etc. This is the most time-consuming step.

$EDITOR debian/control $EDITOR debian/copyright $EDITOR debian/changelog
4

Build the package with debuild

Run debuild from inside the source tree. It compiles the code, assembles the .deb, and runs lintian to check for policy violations.

debuild
📌
The .deb and related files land in the parent directory (one level up from your source tree), not inside it.
