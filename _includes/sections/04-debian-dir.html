04

The debian/ Directory

Every file in debian/ and what it does. The first four are mandatory; the rest you add as needed.

FileMandatory?What it contains
debian/control Always Package name, version, maintainer, dependencies, description. The most important file. One stanza per binary package.
debian/changelog Always Version history in a strict format. The top entry sets the version that gets built. Use dch to edit it, never by hand.
debian/rules Always A Makefile that tells dpkg-buildpackage how to build. Modern packages just call dh $@ — debhelper handles the rest.
debian/copyright Always License and copyright information for every file in the package, in DEP-5 machine-readable format.
debian/patches/ When needed Patch files (created by quilt) that modify upstream source. Applied automatically at build time.
debian/watch Recommended Tells uscan where to find new upstream releases. Used by the Debian QA team to alert maintainers of updates.
debian/install Sometimes Lists extra files to install when the standard build system doesn't place them automatically.
debian/docs Sometimes Extra documentation files to ship in the package.
debian/postinst
debian/prerm
debian/postrm		 Sometimes Shell scripts that run after install / before remove / after remove. Needed for services, caches, users, etc.
debian/source/format Recommended Contains 3.0 (quilt) for most packages. This is the modern default.
debian/upstream/signing-key.asc Security OpenPGP key to verify upstream tarballs. Used by uscan.
debian/salsa-ci.yml CI Enables GitLab CI on Salsa (Debian's GitLab). Runs lintian, piuparts, etc. automatically.
⚠️
Never edit debian/changelog by hand. Always use dch (or debchange) — it handles formatting and timestamps correctly.
