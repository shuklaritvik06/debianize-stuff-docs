Tracking Upstream

uscan Check for a new upstream release
uscan --verbose uscan --download-current-version
Reads debian/watch to find the upstream download page, compares versions, and optionally downloads the new tarball. The Debian QA team runs this regularly for all packages.
uupdate Apply a new upstream tarball to your package
uupdate ../mypkg_2.0.orig.tar.gz
The standard upgrade path. Unpacks the new tarball, copies your debian/ folder in, tries to re-apply your patches, and bumps the changelog. You then fix any patch rejections.
gbp import-orig Import a new upstream release into gbp repo
gbp import-orig --uscan # download + import in one step gbp import-orig ../mypkg_2.0.orig.tar.gz
When using git-buildpackage. Imports the tarball into the upstream branch and merges it into debian/sid (or whichever packaging branch you use).
origtargz Download and verify the upstream orig tarball
origtargz
Downloads the .orig.tar.* matching the current changelog entry and verifies the OpenPGP signature (if debian/upstream/signing-key.asc exists). Easier than curl + manual check.
