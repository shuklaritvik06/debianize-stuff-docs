Building

debuild Build the package (recommended for most work)
debuild debuild -b # binary only debuild -S # source only (for uploading to Launchpad)
The standard command. Wraps dpkg-buildpackage with lintian, signing, and sane defaults. Run from inside the source tree. Output lands one directory up.
dpkg-buildpackage Low-level build command (called by debuild)
dpkg-buildpackage -us -uc # skip signing dpkg-buildpackage -rfakeroot
Directly invokes the debian/rules targets. Use when you need fine-grained control or when debugging the build itself.
sbuild Build in a clean chroot (catches missing build-deps)
sbuild -d unstable mypkg_1.0-1.dsc sbuild -d bookworm --arch=arm64 mypkg.dsc
Builds inside a minimal Debian chroot — the gold standard before uploading. If it fails here but not locally, you have an undeclared build dependency.
gbp buildpackage Build from a git-buildpackage repo
gbp buildpackage gbp buildpackage --git-builder="sbuild"
When your package lives in a gbp-managed git repo. Exports the tree, creates the orig tarball, and calls debuild or sbuild for you.
debputy build Modern build helper (alternative to dh)
debputy build
The next-generation debhelper replacement. If debian/debputy.manifest exists, use this instead of dh.
