Quality & Testing

lintian Check the package against Debian policy
lintian mypkg_1.0-1_amd64.changes lintian --display-info --pedantic mypkg.deb
Run after every build. debuild runs it automatically at the end. Fix all E: and W: before uploading.

Severity levels

E:Error — policy violation, archive will reject the upload
W:Warning — should fix before uploading
I:Info — minor notes, shown with --display-info
P:Pedantic — nitpicky hints, shown with --pedantic

Example output

E: mypkg: binary-without-manpage usr/bin/myprog W: mypkg: new-package-should-close-itp-bug I: mypkg: description-synopsis-might-not-be-phrased-properly P: mypkg: readme-debian-contains-debmake-template
piuparts Test install, upgrade, and purge in a clean environment
piuparts mypkg_1.0-1_amd64.deb
Installs and then purges the package in a throwaway chroot. Catches maintainer script errors, leftover files after purge, and broken post-install steps.
autopkgtest Run the package's own test suite post-install
autopkgtest mypkg_1.0-1.dsc -- schroot unstable-amd64
Runs tests defined in debian/tests/control. This is what the Debian CI system (autopkgtest.debian.net) runs for your package after each upload.
debc List contents of the built .deb
debc mypkg_1.0-1.changes
Shows exactly which files are inside the .deb and where they will be installed. Quick sanity check before uploading — did everything land in the right place?

Example output

drwxr-xr-x root/root 0 2026-11-12 usr/bin/ -rwxr-xr-x root/root 12345 2026-11-12 usr/bin/myprog drwxr-xr-x root/root 0 2026-11-12 usr/share/man/man1/ -rw-r--r-- root/root 890 2026-11-12 usr/share/man/man1/myprog.1.gz -rw-r--r-- root/root 567 2026-11-12 usr/share/doc/mypkg/copyright
dpkg -c / dpkg -I Inspect a .deb manually
dpkg -c mypkg_1.0-1_amd64.deb # list file tree dpkg -I mypkg_1.0-1_amd64.deb # show metadata
-c shows the file tree (same as debc but works without a .changes file); -I shows the metadata: version, dependencies, description.
