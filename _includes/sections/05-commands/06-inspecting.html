Inspecting & Debugging

debdiff Show what changed between two .deb or .changes files
debdiff mypkg_1.0-1.changes mypkg_1.0-2.changes debdiff mypkg_1.0-1.deb mypkg_1.0-2.deb
The standard way to review a packaging update before uploading. Shows file additions, removals, and control-metadata changes between two builds.
dget Download and unpack a source package from the archive
dget https://snapshot.debian.org/archive/.../mypkg_1.0-1.dsc
Downloads the .dsc and all associated source files in one step, then verifies signatures. Essential for inspecting how another maintainer packaged something.
dpkg-depcheck Find which packages a command actually uses
dpkg-depcheck -d make
Runs a command under strace and reports which installed packages provided the files it opened. Useful for finding undeclared runtime dependencies.
dpkg-query Query the local dpkg database
dpkg-query -L mypkg # list installed files dpkg-query -s mypkg # show status/metadata dpkg-query -S /usr/bin/foo # which package owns this file
Inspect what's installed on your machine. -S is especially useful when debugging a "file conflicts with package X" lintian error.
apt-file Find which package provides a file (even if uninstalled)
apt-file search /usr/include/zlib.h apt-file search libssl-dev
When a build fails with "header not found", use this to find the right Build-Depends to add. Searches the full Debian archive, not just installed packages.
