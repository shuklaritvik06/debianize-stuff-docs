Bug Tracking

reportbug File a bug report against a Debian package
reportbug mypkg
Collects system info, checks for existing bugs, and mails a report to the Debian Bug Tracking System. Use when you find a problem in any installed package.
bts Interact with the Debian Bug Tracking System from the CLI
bts show 123456 # view bug details bts close 123456 1.0-2 # close bug, fixed in version bts retitle 123456 "New title" bts reassign 123456 otherpkg
As a maintainer, use this to manage bugs against your packages: close them when fixed, retitle when the report is misleading, reassign if it belongs to another package.
devscripts: rc-alert List release-critical bugs in packages you maintain
rc-alert --maintainer you@example.com
Shows open RC (release-critical) bugs for your packages. If any exist when a freeze comes, your package may be dropped from the release.
wnpp-check Check if a package is already being worked on
wnpp-check mypkg
Before packaging something new, check if there's an existing ITP (Intent To Package) or RFP (Request For Package) bug. Avoids duplicated effort.
