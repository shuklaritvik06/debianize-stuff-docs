Package Creation

debmake Generate the debian/ template folder
debmake
Run once, inside unpacked upstream source. Reads the existing build system (Makefile, CMake, etc.) and writes a skeleton debian/ folder. You then edit those templates.
dh_make Older template generator (alternative to debmake)
dh_make --single -f ../mypkg_1.0.orig.tar.gz dh_make --indep --createorig
Pre-dates debmake; still widely documented. Use debmake for new packages — it generates cleaner templates.

Flag guide

--singleone binary package, compiles to native code
--indeparchitecture-independent (scripts, data, docs)
--libraryC/C++ library — generates libfoo + libfoo-dev packages
--pythonPython module or package
-f ../pkg.orig.tar.gzuse this existing tarball
--createorigcreate a tarball from the current directory (no tarball yet)

-f and --createorig are redundant together — if you have a tarball use -f; if you don't use --createorig.

dch / debchange Edit debian/changelog correctly
dch -v 1.0-1 "Initial Debian packaging" # set exact version dch -i "Fix segfault on empty input" # increment Debian revision dch -a "Update man page" # add bullet to open entry dch -r "" # mark ready, set distribution
Always use this instead of a text editor. -i increments the Debian revision (1.0-1 → 1.0-2); -v sets an exact version; -r changes UNRELEASED → unstable and stamps the timestamp.

Resulting debian/changelog

mypkg (1.0-2) unstable; urgency=medium * Fix segfault on empty input (Closes: #123456) * Update man page -- Ritvik Shukla <ritvik@example.com> Wed, 12 Nov 2026 20:00:00 +0530 mypkg (1.0-1) unstable; urgency=low * Initial Debian packaging -- Ritvik Shukla <ritvik@example.com> Mon, 09 Nov 2026 12:00:00 +0530

Two spaces before the date in the trailer line is mandatory — one missing space breaks the build. The top stanza's version is what gets built; older stanzas are read-only history.

wrap-and-sort Sort and wrap debian/ control fields
wrap-and-sort -a
Run before committing. Normalizes the formatting of debian/control, debian/copyright, and similar files so diffs stay clean.
cme fix dpkg Auto-fix control file syntax errors
cme fix dpkg
When debian/control has syntax or policy issues, this tool reads and rewrites it to fix common problems automatically.
