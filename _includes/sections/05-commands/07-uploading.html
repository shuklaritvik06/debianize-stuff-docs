Uploading

dput Upload a package to the Debian archive (or Launchpad)
dput ftp-master mypkg_1.0-1_source.changes dput ppa:you/myppa mypkg_1.0-1_source.changes
The standard upload tool. Reads ~/.dput.cf for host configuration. ftp-master is the main Debian archive; ppa: targets are Ubuntu PPAs on Launchpad.
dput-ng Modern replacement for dput
dput ftp-master mypkg_1.0-1_source.changes
Drop-in replacement with better error messages and support for more upload targets. The same command syntax as dput.
debsign Sign a .changes or .dsc file
debsign mypkg_1.0-1_source.changes debsign -k YOURKEYID mypkg.dsc
Signs the files with your OpenPGP key. Required before uploading to the Debian archive. debuild calls this automatically at the end of a build if your key is configured.
gbp push Push packaging repo to Salsa
gbp push
Pushes all relevant branches and tags to the remote (usually Salsa, Debian's GitLab). Run after a successful upload to keep the git repo in sync.
