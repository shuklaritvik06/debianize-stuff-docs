Quick Reference

The commands you reach for most often, one line each.

Generate debian/ templates
debmake
Add a changelog entry
dch -i "message"
Build the package
debuild -us -uc
Build source only
debuild -S -sa
Build in clean chroot
sbuild -d unstable pkg.dsc
Check policy compliance
lintian pkg.changes
List .deb contents
debc pkg.changes
Test install/purge
piuparts pkg.deb
Check for new upstream
uscan --verbose
Apply new upstream
uupdate ../pkg_2.0.orig.tar.gz
New patch
dquilt new fix-name.patch
Save patch edits
dquilt refresh
Sort control fields
wrap-and-sort -a
Find package for file
apt-file search /path/to/file
Diff two builds
debdiff old.changes new.changes
Upload to Debian
dput ftp-master pkg.changes
Close a bug
bts close 123456 1.0-2
File a bug report
reportbug packagename
📖
The authoritative reference is the Debian Policy Manual and the Guide for Debian Maintainers. Both are available at debian.org/doc/ and as packages: apt install debian-policy debmake-doc.
