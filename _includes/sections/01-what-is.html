What is Debian Packaging?

The plain-English explanation before we touch any tools.

When you download software on Debian/Ubuntu, you use apt install something. That "something" is a .deb package — a compressed archive that bundles the program's files together with metadata: what other packages it needs, who made it, what version it is, where files should land on your system.

Debian packaging is the process of wrapping an upstream program (some open-source project you downloaded as source code) inside a .deb so anyone on Debian can install it cleanly with apt.

The wrapping lives in a special folder called debian/ that you create inside the source tree. That folder is what you spend most of your time editing.

💡
Just for yourself? If you only need the software locally, compile it and install into /usr/local/. Packaging is worth the effort when you want to share it with others through the Debian archive.
TermWhat it means
